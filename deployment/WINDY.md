# Карта Windy

Карта открывается в разделе «Карта ветра» основного дашборда. Она использует Windy Map Forecast API и загружает Leaflet/Windy только при открытии раздела. Координаты двух установок берутся из config.json. Встроенная карта имеет собственную шкалу текущего прогнозного времени, частицы ветра и кнопку перехода к установкам.

Это отдельный погодный слой. Модель мощности продолжает использовать прежний Open-Meteo ECMWF IFS и ветер 100 м. Карта по умолчанию использует GFS у поверхности, поэтому её значения могут отличаться. Выбранная историческая дата дашборда не передаётся в живую карту. Источник, модель, уровень и целевое время карты отображаются отдельно. Встраивание в iframe изолирует глобальные стили Windy от приложения; логотип и атрибуция провайдера не скрываются.

Локальная настройка: добавьте одну строку `WINDY_MAP_API_KEY=ваш_ключ` в .env в корне проекта. Этот файл исключён из Git. Читается только данный параметр; остальные секреты из файла не отправляются браузеру. Переменная окружения с тем же именем имеет приоритет, в том числе пустое значение для отключения карты.

В Render параметр при необходимости задаётся через Environment → WINDY_MAP_API_KEY. Он не встроен в render.yaml, исходники HTML, снимок прогнозов или пакет модели. Без ключа прогноз мощности работает, а карта показывает понятное сообщение. Текущий Blueprint не требует ключа для запуска сервиса.

Map Forecast — браузерная интеграция: посетитель может увидеть её ключ в сетевых запросах. Хранение в окружении предотвращает попадание ключа в Git, но не делает браузерный ключ секретным. В панели Windy ограничьте разрешённые домены фактическим адресом сайта; для разработки используйте подходящее ограничение локального адреса. Не вставляйте вместо него ключ закрытого серверного API.

По [документации Windy](https://api.windy.com/map-forecast/docs) бесплатный Testing предназначен только для разработки и не разрешён для production. Перед публичным рабочим размещением нужно проверить тариф/условия ключа. Интеграция в локальный прототип не означает, что production-лицензия получена.

Статус «Погодный слой загружен» появляется по событию redrawFinished SDK, а не только по успешному HTTP-запросу конфигурации. При недоступном сервере, отсутствии ключа, ошибке библиотеки или тайм-ауте предусмотрено сообщение с повторной загрузкой. Отказ карты не подменяется мок-погодой и не блокирует прогноз мощности.

Маршруты: /map/windy — страница внутри iframe; /map/config — минимальная конфигурация браузерной карты с Cache-Control: no-store. Исторические /forecast, модель и цикл агента не менялись.
